# 🟡 Pacman AI — Search Algorithms

> An Artificial Intelligence project developed for **CSCI 363: Artificial Intelligence** at Queens College, CUNY.

---

## 📖 Introduction

In this project, I developed a **Pacman agent** capable of navigating through maze environments, finding paths to specific locations, and efficiently collecting food.

The project focuses on implementing and applying **general search algorithms** to solve different Pacman scenarios.

---

## 🎯 Project Objectives

- 🧭 Find paths through maze environments
- 🍒 Efficiently collect food
- 🧠 Implement general search algorithms
- ⚡ Compare different search strategies
- 🗺️ Apply AI search techniques to pathfinding problems

---

## 🧠 Algorithms & Concepts

This project covers several fundamental Artificial Intelligence concepts:

- **Depth-First Search (DFS)**
- **Breadth-First Search (BFS)**
- **Uniform Cost Search (UCS)**
- **A* Search**
- **Heuristics**
- **State-Space Search**
- **Graph Traversal**
- **Pathfinding**

## 🎮 Project Overview

The Pacman agent makes decisions based on the current state of the maze.

Different search algorithms produce different paths and performance characteristics. The goal is to find solutions that are both **correct** and **efficient**.
